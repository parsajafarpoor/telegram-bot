# ربات یادآوری تولد (Saheb Naghsh)

این ربات نام و تاریخ تولد افراد را از یک فایل اکسل می‌خواند و **۵ روز قبل** از تولد هر نفر،
یک پیام یادآوری با تاریخ **شمسی** در کانال `@tavalod1s` ارسال می‌کند.

## پیش‌نیازها

- Python 3.10+ (نصب است)
- ربات `@sahebnaghsh_bot` باید در کانال `@tavalod1s` **ادمین** باشد (طبق گفته شما همین‌طور است) و دسترسی «ارسال پیام» داشته باشد.

## نصب

```bash
cd "D:\sahebnaghsh site\telegram-birthday-bot"
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

(این مرحله قبلاً انجام شده و محیط مجازی `.venv` آماده است.)

## تنظیمات (.env)

فایل `.env` از قبل با این مقادیر ساخته شده:

```
BOT_TOKEN=<توکن ربات — از قبل تنظیم شده>
CHAT_ID=@tavalod1s
EXCEL_PATH=birthdays.xlsx
NOTIFY_TIME=09:00
DAYS_BEFORE=5
```

اگر خواستید ساعت ارسال یا تعداد روزهای یادآوری را عوض کنید، همین فایل را ویرایش کنید.

## فایل اکسل تولدها

فایل `birthdays.xlsx` باید کنار `main.py` باشد و دو ستون داشته باشد:

| نام          | تاریخ تولد  |
|--------------|-------------|
| علی رضایی    | 1370/05/12  |
| سارا محمدی   | 1368/11/02  |

- ستون تاریخ می‌تواند **شمسی** (`1370/05/12`) یا **میلادی** (سلول تاریخ واقعی اکسل، یا متن مثل `1991-08-03`) باشد؛ ربات خودش تشخیص می‌دهد.
- نام ستون‌ها می‌تواند «نام» یا «تاریخ تولد» باشد (یا معادل انگلیسی: `Name` / `Birthday`).
- یک نمونه با اجرای این دستور ساخته می‌شود:

```bash
.venv\Scripts\python.exe make_sample.py
```

**فایل واقعی خودتان را جایگزین `birthdays.xlsx` کنید.**

## اجرا

```bash
.venv\Scripts\python.exe main.py
```

با اجرای این دستور، ربات:
- هر روز ساعت تنظیم‌شده (پیش‌فرض ۹ صبح به وقت تهران) فایل اکسل را چک می‌کند.
- برای هر کسی که ۵ روز دیگر تولدش است، پیام یادآوری به کانال `@tavalod1s` می‌فرستد.

### دستورهای قابل استفاده داخل تلگرام (در چت خصوصی با ربات)

- `/start` — راهنما
- `/list` — نمایش لیست تولدهای ۳۰ روز آینده (فقط برای شما، تستی)
- `/check` — اجرای فوری بررسی؛ اگر کسی دقیقاً ۵ روز تا تولدش مانده باشد، **همین الان** به کانال پیام می‌فرستد (برای تست واقعی بودن ارسال)
- `/reload` — خواندن دوباره فایل اکسل (بعد از این‌که فایل را آپدیت کردید)
- `/chatid` — نمایش آیدی عددی هر چتی که این دستور در آن زده شود

## اجرای دائمی (۲۴ ساعته)

برای این‌که یادآوری‌ها هر روز به‌صورت خودکار ارسال شوند، این برنامه باید **همیشه در حال اجرا** باشد.
چند گزینه:

1. **ساده‌ترین حالت روی همین سیستم:** برنامه را در یک ترمینال باز نگه دارید (یا با `pythonw.exe main.py` به‌صورت بی‌صدا در پس‌زمینه اجرا کنید). اگر سیستم خاموش/ریستارت شود، باید دوباره اجرا کنید.
2. **Task Scheduler ویندوز:** یک Task بسازید که هنگام روشن شدن ویندوز، دستور بالا را اجرا کند.
3. **بهترین گزینه برای پایداری:** اجرا روی یک VPS/سرور کوچک (لینوکس) به همراه `systemd` یا `pm2`، تا حتی با خاموش بودن سیستم شخصی شما هم ربات کار کند.

## نکته امنیتی

فایل `.env` حاوی توکن ربات شماست و در `.gitignore` قرار دارد تا اگر این پوشه را در گیت/گیت‌هاب قرار دادید،
توکن به‌صورت عمومی منتشر نشود. این توکن را با کسی به اشتراک نگذارید؛ هر کسی که آن را داشته باشد می‌تواند
به‌جای شما با ربات پیام بفرستد.
